# QuizCraft EDU Pro

教科書の写真・PDF・Word・PowerPoint・動画・URLから、Kahoot!向けの四択クイズを作成できる教員向けツールです。ブラウザで開く単一のHTMLファイルで動作し、インストールは不要です。

- 現在のバージョン： Ver 3.3
- 本体： `index.html`（ダブルクリックで起動）
- 詳しい使い方は同梱の「操作説明書.docx」、変更履歴は `readme.txt` を参照してください。

## 主な機能
- 資料の取り込み（写真OCR／PDF／Word／PowerPoint／字幕・文字起こし／動画URL／Webページ）
- AI（Google Gemini、先生ご自身のAPIキー）による問題生成・教材本文の整理
- 問題編集・品質チェック・指導要領（資質・能力の三つの柱）への対応付け
- 誤答インサイト、クイズ構成分析
- Kahoot!向け Excel（.xlsx）／TSV／CSV 出力
- 校内問題バンク、共同編集（同一ブラウザ内タブ間）

## プライバシー
既定の「完全ローカルモード」では教材・問題データを外部に送信しません。OCR・AI生成などを使う場合のみ、先生ご自身のGoogle AI Studio APIキーでGemini APIへ接続します。APIキーはプロジェクトファイルには保存されません。
