# QuizCraft EDU Pro

教科書の写真・PDF・Word・PowerPoint・動画・URLから教材を取り込み、Kahoot!向けの四択クイズを作成するための、**単一HTMLファイルで完結する**先生向けツールです。ビルド不要・サーバー不要で、ブラウザで `index.html` を開くだけで動作します。

> 🔒 既定は完全ローカルモードです。写真OCR・動画URL解析・Webページ解析・Geminiによる問題生成など一部機能のみ、先生個人のGoogle AI Studio APIキーを使う「接続モード」が必要です。詳細は [プライバシーとデータの扱い](#プライバシーとデータの扱い) を参照してください。

## 特徴

- **単一HTMLファイル**：`index.html` 1つだけで動作。npm install もサーバーも不要
- **資料の自動取り込み**：写真・PDF・Word・PowerPoint・動画・URLを追加すると、自動でOCR・解析し、教材本文としてまとめる「ソースライブラリ」方式（NotebookLM的な体験）
- **ローカル/接続の境界が明確**：どの機能が外部通信を伴うかをUI上で常に明示
- **Kahoot!向け出力**：Excel（.xlsx）・公式テンプレート貼り付け用TSV・CSVに対応
- **評価設計support**：資質・能力の三つの柱（知識・技能／思考・判断・表現／主体的に学習に取り組む態度）への関連付け
- **誤答分析**：回答データ（CSV/JSON）を読み込み、つまずきの傾向から復習問題を提案
- **校内問題バンク・共同編集**：良問を蓄積して再利用し、同一ブラウザの別タブ間でリアルタイムに受け渡し

## 使い方（クイックスタート）

1. `index.html` をダブルクリックしてブラウザで開く（Chrome・Edge・Safari推奨）
2. サイドバーの「資料の取り込み」で、教科書の写真やPDFなどを追加する（追加すると自動で文字を読み取ります）
3. 「資料と生成設定」で学年・教科・難易度などを設定し、「問題を生成」を押す
4. 「問題編集」で生成された問題を確認・修正する
5. 「品質チェック」で問題点がないか確認する
6. 「出力」からKahoot!向けのExcel/TSV/CSVを書き出す

日本語の詳しい操作説明は、同梱の `操作説明書.docx` を参照してください。

## 対応ソース形式

「資料の取り込み」ページで、以下をソースとして追加できます。追加すると自動的にキューに入り、順番に処理されます。

| 種別 | 処理方法 | モード |
|---|---|---|
| 写真（教科書ページなど） | Gemini Vision（推奨）またはローカルTesseract.jsでOCR | 接続モード |
| PDF（テキスト情報あり） | PDF.jsで直接テキスト抽出 | ローカル |
| スキャンPDF（画像PDF） | Gemini VisionまたはローカルTesseract.jsでOCR | 接続モード |
| Word（.docx） | ブラウザ内でXMLを直接展開してテキスト抽出 | ローカル |
| PowerPoint（.pptx） | スライド範囲を指定してテキスト抽出 | ローカル |
| 字幕ファイル（.srt/.vtt）・文字起こしテキスト | タイムスタンプを除去してテキスト化 | ローカル |
| 動画URL（YouTubeなど） | Gemini APIに動画URLを渡して要約・書き起こし | 接続モード |
| WebページURL | Gemini APIにURLを渡して本文を整理・取得 | 接続モード |

複数ソースの内容は自動で1つの教材本文に合算されます。各ソースは個別に「教材本文に含める／含めない」を切り替えたり、抽出結果を手動で修正したりできます。

## ローカルモードと接続モード

このアプリには2つの動作モードがあります。

- **完全ローカルモード（既定）**：教材・問題データを一切外部送信しません。テキスト貼り付け、TXT/MD/CSV/HTML/JSON、Word、PowerPoint、PDF（テキスト抽出）、字幕・文字起こしの取り込みが可能です。
- **接続モード**：先生個人のGoogle AI Studio APIキーを登録すると使えるようになります。写真・スキャンPDFのOCR（Gemini VisionまたはローカルTesseract）、動画URL・WebページURLの解析、Geminiによる問題生成が可能になります。

モードの切り替えは「モード・接続」ページから行います。UI上では、ローカルで完結する機能には緑色、接続が必要な機能には紫色のタグが表示され、常に区別できるようになっています。

## プライバシーとデータの扱い

- Gemini APIキーは**ブラウザのメモリ内にのみ保持**され、アプリやプロジェクトファイルには保存されません（ブラウザを閉じると消えます。任意で「このブラウザに記憶する」設定も選べます）
- 接続モードで実行した機能（写真OCR・動画解析・URL解析・Gemini問題生成）のみ、該当データがGoogleのGemini APIに送信されます。それ以外の操作は一切外部送信されません
- プロジェクトデータ（問題・教材本文など）は、ブラウザの`localStorage`にのみ保存されます。サーバーへの自動アップロードはありません
- 添付した写真・PDFなどの**ファイル本体はメモリ上でのみ扱われ、保存されません**。ページを再読み込みすると再度ファイルを選び直す必要があります（抽出済みのテキストはプロジェクトに保存されます）

## 出力形式

「出力」ページから以下の形式で書き出せます。

- **Kahoot!向けExcel（.xlsx）**：ブラウザ内で生成。四択問題をまとめて出力
- **公式テンプレート貼り付け用TSV**：Kahoot!公式Excelテンプレートの先頭データ行に貼り付け可能なタブ区切りテキスト
- **CSV**：Excel・Googleスプレッドシートでの確認・編集用
- **評価対応表CSV**：問題と評価観点（三つの柱）の対応表

Kahoot!の仕様に合わせ、問題文95文字・選択肢60文字・制限時間5/10/20/30/60/120秒の範囲で出力されます。

## 技術構成

- 素のHTML / CSS / JavaScript（フレームワーク・ビルドツール不使用）
- 状態管理：単一の `state` オブジェクト＋`localStorage`への自動保存
- PDF解析：[pdf.js](https://mozilla.github.io/pdf.js/)（CDN経由、初回のみ動的読み込み）
- ローカルOCR：[Tesseract.js](https://tesseract.projectnaicha.com/)（CDN経由、接続モード時のみ読み込み）
- 画像・URL・動画解析：Google Gemini API（先生個人のAPIキーで直接呼び出し）
- Excel出力：ブラウザ内で.xlsxを直接生成

## 開発・カスタマイズ

- すべてのロジックは `index.html` 内の `<script>` タグにまとめられています
- 画面遷移は `navigate(page)` 関数がページの表示切り替えとページごとの再描画関数（`renderXxx()`）を呼び出す構成です
- 操作は `document.addEventListener('click', ...)` に集約された `data-action` 属性ベースのイベント委譲で処理されます
- 資料の取り込み機能（写真・PDF・動画・URL）は「ソースライブラリ」方式で、`state.sources` 配列に各ソースのメタデータ（ステータス・抽出テキストなど）を保持し、`recombineSources()` が自動的に教材本文へ合算します。ファイル実体（`File`/`Blob`）は永続化せず、`sourceFiles` というモジュール内の一時オブジェクトにのみ保持しています
- 新しいソース種別を追加する場合は、`addSource()` でソースを登録し、`processSourceItem()` に処理分岐を追加してください

## 既知の制限事項

- OCR・Gemini Vision・動画解析の結果は完璧ではありません。特に数字・年号・単位は誤読されやすいため、生成された問題は必ず元の資料と照合してください
- ページを再読み込みすると、追加済みファイルの実体（写真・PDFなど）は失われます（抽出済みのテキストは保持されます）。再処理が必要な場合はファイルを選び直してください
- ブラウザの`localStorage`容量（多くの環境で5〜10MB程度）を超えると保存に失敗します。大量の写真ソースを扱う場合はご注意ください
- パスワード保護されたファイル、複雑な図表、縦書き文書、数式は正確に抽出できない場合があります
