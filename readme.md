# Quiz Generator App

各種ソース（テキスト、ファイル、Web APIなど）から自動で問題を生成し、クイズ形式で学習・回答ができるアプリケーションです。

---

## 🚀 主な機能

* 多彩なソース対応: さまざまな情報源からクイズ問題を生成
* クイズ回答モード: スコア測定や解説表示を備えたクイズ機能
* 外部API連携: 最新の生成AIモデルや外部サービスを活用した高度な問題作成

---

## 🛠 動作環境・事前準備

### 動作要件
* [言語/フレームワーク名]: vX.X以上（例: Python 3.10+ / Node.js 18+）
* 必須パッケージの詳細は requirements.txt（または package.json）を参照してください。

### ⚠️ 【重要】APIキーの管理と注意点
本アプリで外部連携機能（生成AI API等）を利用する場合、各自で発行したAPIキーが必要となります。セキュリティ保護のため、以下のルールを必ず守って管理してください。

1. **GitHubにAPIキーを送信（コミット）しない**
   * .env などの環境変数ファイルにキーを記述し、絶対にコード内に直接書き込まないでください。
   * .gitignore に .env が含まれていることを事前に必ず確認してください。
2. **キーの利用制限・予算設定**
   * 予期せぬ高額請求を防ぐため、連携先サービス（OpenAI等）のダッシュボードで利用上限（Usage Limit）を設定することをおすすめします。
3. **キー漏洩時の対処**
   * 万が一キーを公開リポジトリに誤ってプッシュした場合は、直ちに該当のAPIキーを無効化（Revoke）し、新しいキーを再発行してください。

## 📦 インストール方法

1. リポジトリのクローン
git clone https://github.com/username/repository-name.git
cd repository-name

2. 依存関係のインストール
# 例：Pythonの場合
pip install -r requirements.txt

# 例：Node.jsの場合
npm install

3. 環境変数の設定
ルートディレクトリにある .env.example をコピーして .env を作成し、必要なAPIキーを設定してください。
cp .env.example .env

.env 内の記述例：
API_KEY=your_actual_api_key_here

---

## 📖 操作手順・使い方

### 1. アプリの起動
# 起動コマンドを入力（例：python app.py / npm start など）
python main.py

### 2. 問題の生成
1. ソースの選択: クイズの元となる情報（テキスト入力、ファイルアップロード、URL指定など）を選択します。
2. 条件設定: 問題数、難易度、出題形式（択一式・○×式など）を設定します。
3. 生成実行: 「問題生成」ボタンを押すと、ソースを解析して自動でクイズが作成されます。

### 3. クイズの解答
* 画面に表示される問題に対し、正しいと思う選択肢を選んで「回答」を押します。
* 正誤判定とともに解説が表示されます。
* すべての問題が終わると最終スコアを確認できます。
